Variant effect predictions for 783 transporter and ion-channel genes

Look up any of the 349,056 ClinVar variants in these genes. Every variant has a pathogenicity score and an evidence level, set with the calibration method ClinGen recommends, for use with the ACMG/AMP guidelines. Missense, splice, intronic, frameshift and all other variant types are included.

For example SLC19A2, CFTR, KCNQ1,

  • 349,056 ClinVar variants
  • 783 genes
  • 13 variant types
  • 176,153 missense variants with predicted activity
