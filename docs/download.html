How to cite

If you use these predictions, please cite:

Abo-Dahab Y, Chun J, Giacomini KM. Calibrated pathogenicity predictions for 783 human transporter and ion-channel genes. Version 1.0.1, 25 October 2026. https://joevondahab.github.io/transporter-variants/

If you use the With AlphaMissense version, please also cite:

Cheng J, Novati G, Pan J, et al. Accurate proteome-wide missense variant effect prediction with AlphaMissense. Science 381, eadg7492 (2023). doi:10.1126/science.adg7492

Data sources

  • Variants and classifications from ClinVar.
  • Protein sequences, membrane topology and functional sites from UniProtKB (CC BY 4.0).
  • Protein structures from AlphaFold DB (CC BY 4.0), loaded from alphafold.ebi.ac.uk when you open a gene page.
  • Evidence thresholds from Tavtigian SV et al., Genet Med 20, 1054–1060 (2018).
